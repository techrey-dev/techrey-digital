# Techrey Digital

> Aplikasi React operasional lokal tersedia di folder `app/`. Petunjuk menjalankan, konfigurasi OAuth/WhatsApp/QRIS/AI, dan batas infrastruktur ada di `app/README.md`.

Repository ini menyimpan prototipe asli sebagai referensi serta aplikasi React yang aktif. Folder `prototype/` tidak digunakan sebagai runtime produksi.

## Mulai

```powershell
cd app
npm install
npm run dev
```

Buka `http://127.0.0.1:5173/`. Konfigurasi OAuth, WhatsApp, QRIS DANA Bisnis, serta AI dijelaskan di `app/README.md`.

## Isi paket
- prototype/: HTML, CSS, JavaScript dan aset sumber versi terbaru, termasuk dashboard admin. Referensi visual/fungsional yang tetap disimpan.
- app/: aplikasi React dan server yang aktif.
- BRIEF-PRODUK.md: layanan, interaksi, alur admin, batas demo, dan tahapan sistem nyata.

## Yang sudah tersedia
Beranda, empat layanan, contoh karya, FAQ, formulir kebutuhan, akun pelanggan, workspace admin, pencarian/filter, detail pesanan, penawaran, QRIS DANA Bisnis manual, progres, hasil privat, dan revisi.

## Status aplikasi
React/TypeScript, objek 3D WebGL, OAuth Google/GitHub, kepemilikan pesanan, SQLite, file privat lokal, QRIS merchant manual berbasis konfigurasi, tautan WhatsApp, dan AI server-side berbasis konfigurasi tersedia di `app/`. Infrastruktur terkelola, notifikasi WhatsApp otomatis, dan publikasi belum diaktifkan.
